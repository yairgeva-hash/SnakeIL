# בלשי הטבע — גרסה 0.9

גרסה זו מבצעת מעבר מאב־טיפוס בקובץ יחיד לתשתית מודולרית שניתן להרחיב למינים, משלחות וסוגי אינטראקציה נוספים.

## מבנה חדש

- `app/components` — מסכים ורכיבי ממשק עצמאיים
- `app/data` — מינים, משימות ותיקי חקירה מבוססי נתונים
- `app/lib` — לוגיקת משחק משותפת
- `app/types` — טיפוסים מרכזיים של מנוע המשחק
- `app/page.tsx` — מנהל הזרימה והמצב בלבד

## עיקרון מנוע המשחק

תיקי החקירה מוגדרים ב־`app/data/investigations.ts`. כל תיק מתאר צילום, שלב התבוננות, שאלת זיהוי, משוב ורמת קושי. ה־UI קורא את הנתונים ואינו מכיל עוד את תוכן השאלות עצמו.

## הרצה

```bash
npm install
npm run dev
```

## בטיחות

האפליקציה מיועדת ללמידה מתמונות בלבד. אין להתקרב, לגעת או לנסות ללכוד נחש לצורך זיהוי.
