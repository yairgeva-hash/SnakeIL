# בלשי הטבע — v1.2 Vertical Slice

גרסת MVP ממוקדת שמיישמת תיק חקירה אחד מלא: **הצפע והמתחזה**.

## מה חדש
- היררכיה ברורה: תעלומה → למידה קצרה → תרגול → פתרון → תגמול.
- הצלחה ראשונה בתוך פחות מחצי דקה.
- תגמולים זעירים לאורך התיק וראיות שנאספות.
- למידה חזותית של דוגמת גב, מבנה גוף והסכנה שבהסתמכות על צבע בלבד.
- חקירת סיום עם תמונת שטח חדשה.
- מסך "התיק נסגר" ופתיחת כרטיס באנציקלופדיה.
- אין חסימה או ענישה על טעות; ניתן לנסות שוב מיד.

## הפעלה
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
